Keep completed installation, browser sign-in and verified connection intact.
For a current setup code or unfinished connection, use [connect](../connect/SKILL.md)
and its setup procedure in this same chat. With no current code, direct the user
to their signed-in Agent Upskill setup page for a fresh attempt; do not fabricate
verification. An already connected user can go directly to
[delivery](../delivery/SKILL.md). Offer delivery as an optional per-computer step;
declining it never resets the working plugin. Do not infer device enrollment
from installation, OAuth or a website save.
